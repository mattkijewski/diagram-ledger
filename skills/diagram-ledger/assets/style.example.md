# Project diagram style

Copy this file to `diagram-ledger.style.md` in your project root and customize it.

- Audience: engineers and product collaborators.
- Preferred editable format: draw.io unless the request specifies another format.
- Output folder: `diagrams/<subject-and-view>/` in the active project root, one folder per diagram.
- Filenames: descriptive lowercase kebab-case subject and view; matching stems for source and exports.
- Canvas: #F8FAFC. Surface: #FFFFFF.
- Primary text: #172033. Secondary text: #475569.
- Connections and essential borders: #64748B.
- Emphasis: #155E75 on #ECFEFF.
- Typeface: Arial, Helvetica, sans-serif; monospace only for code-like text.
- Language: plain English, sentence-case labels.
- Notation: label what each boundary means; use words as well as color for status.
- Export destination: documentation at approximately 1000 px display width.

Add project vocabulary and approved terminology here. Keep credentials, private endpoints, and personal information out of shared style files.
