# Name and positioning

**Name:** Diagram Ledger
**Skill identifier:** `diagram-ledger`
**Tagline:** Draw clearly. Revise deliberately. Leave a record.

The name connects an editable diagram with a reviewable record of its changes. It supports different editors and diagram types while emphasizing continuity between revisions.

## What the project offers

- Editable draw.io, Excalidraw, Mermaid and SVG sources, plus beta import destinations.
- Conversational brainstorming with decisions and open questions saved beside the diagram.
- Exact baseline capture and narrow permitted changes for supported formats.
- Required outcomes that verify the requested result.
- Readable receipts containing exact sources, the contract and file fingerprints.
- Portable installation and updates with retained backups.
